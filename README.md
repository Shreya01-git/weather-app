# Weather App

This is a simple weather app created using HTML, CSS, and JavaScript. It displays the current weather information based on user input or location.

## 🔧 Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 Features
- Live weather data using API
- Responsive design for mobile and desktop
- Clean and simple UI

## 📦 How to Use
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Enter your city name to get weather info.
